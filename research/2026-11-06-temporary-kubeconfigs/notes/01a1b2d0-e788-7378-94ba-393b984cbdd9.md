# Create a Kubeconfig for a Kubernetes Service Account

Generate a kubeconfig for a Kubernetes Service Account using omnictl for secure, token-based cluster access.

This guide walks you through generating a kubeconfig for a Kubernetes Service Account using `omnictl`.

## Prerequisites

To follow this guide, you must have:

* [`omnictl` installed and configured](/omni/getting-started/install-and-configure-omnictl)
* [A cluster created in Omni](/omni/getting-started/create-a-cluster)

Kubernetes Service Accounts authenticate to a Kubernetes cluster. If you need to authenticate to Omni itself, see [Omni Service Accounts](/omni/omni-cluster-setup/create-an-omni-service-account) instead.

## [​](#create-the-kubernetes-service-account-kubeconfig) Create the Kubernetes service account kubeconfig

Run the following command to generate the kubeconfig:

```
omnictl kubeconfig --service-account --cluster <cluster> --user <username> <path to kubeconfig> omnictl  kubeconfig --service-account --cluster < cluste r> --user < usernam e> < path  to  kubeconfi g>
```

Replace the placeholders with your own values:

* : The name of your cluster in Omni
* : Any username you want to assign to the service account
* : The file path where the kubeconfig will be written

This creates a service account token with the specified username and writes a kubeconfig for the given cluster to the path you provided. You can then use this kubeconfig with `kubectl` as normal. To invalidate the kubeconfig before its token expires, see [Revoke Kubernetes Access Tokens](/omni/security-and-authentication/revoke-kubernetes-access-tokens).
