# infisical Provider

This provider allows you to interact with Infisical

## [Example Usage](https://registry.terraform.io/providers/Infisical/infisical/latest/docs#example-usage)

Copy
```
terraform {
  required_providers {
    infisical = {
      # version = <latest version>
      source = "infisical/infisical"
    }
  }
}

provider "infisical" {
  host = "https://app.infisical.com" # Only required if using self hosted instance of Infisical, default is https://app.infisical.com
  auth = {
    # organization_slug = "<organization slug to scope the session to sub-org>"
    universal = {
      client_id     = "<machine-identity-client-id>"
      client_secret = "<machine-identity-client-secret>"
    }
  }
}

# Authenticate via environment variables instead of the auth block:
#
# provider "infisical" {}
#
#
# Authenticate via Universal Auth:
# export INFISICAL_AUTH_METHOD="universal"
# export INFISICAL_UNIVERSAL_AUTH_CLIENT_ID="<machine-identity-client-id>"
# export INFISICAL_UNIVERSAL_AUTH_CLIENT_SECRET="<machine-identity-client-secret>"
#
# Authenticate via Token Auth:
# export INFISICAL_AUTH_METHOD="token"
# export INFISICAL_TOKEN="<machine-identity-token>"
#
# Authenticate via OIDC Auth:
# export INFISICAL_AUTH_METHOD="oidc"
# export INFISICAL_MACHINE_IDENTITY_ID="<machine-identity-id>"
# export INFISICAL_AUTH_JWT="<oidc-jwt>"
#
# Authenticate via Kubernetes Auth:
# export INFISICAL_AUTH_METHOD="kubernetes"
# export INFISICAL_MACHINE_IDENTITY_ID="<machine-identity-id>"
# export INFISICAL_KUBERNETES_SERVICE_ACCOUNT_TOKEN="<service-account-token>"
# # Or use the token file path (defaults to /var/run/secrets/kubernetes.io/serviceaccount/token):
# # export INFISICAL_KUBERNETES_SERVICE_ACCOUNT_TOKEN_PATH="<path-to-service-account-token>"
#
# Authenticate via AWS IAM Auth:
# export INFISICAL_AUTH_METHOD="aws_iam"
# export INFISICAL_MACHINE_IDENTITY_ID="<machine-identity-id>"
```

## [Schema](https://registry.terraform.io/providers/Infisical/infisical/latest/docs#schema)

### [Optional](https://registry.terraform.io/providers/Infisical/infisical/latest/docs#optional)

*   [`auth`](https://registry.terraform.io/providers/Infisical/infisical/latest/docs#auth-1) (Attributes) The configuration values for authentication (see [below for nested schema](https://registry.terraform.io/providers/Infisical/infisical/latest/docs#nestedatt--auth))
*   [`client_id`](https://registry.terraform.io/providers/Infisical/infisical/latest/docs#client_id-1) (String, Sensitive) (DEPRECATED, Use the `auth` attribute), Machine identity client ID. Used to fetch/modify secrets for a given project.
*   [`client_secret`](https://registry.terraform.io/providers/Infisical/infisical/latest/docs#client_secret-1) (String, Sensitive) (DEPRECATED, use `auth` attribute), Machine identity client secret. Used to fetch/modify secrets for a given project
*   [`host`](https://registry.terraform.io/providers/Infisical/infisical/latest/docs#host-1) (String) Used to point the client to fetch secrets from your self hosted instance of Infisical. If not host is provided, [https://app.infisical.com](https://app.infisical.com/) is the default host. This attribute can also be set using the `INFISICAL_HOST` environment variable
*   [`service_token`](https://registry.terraform.io/providers/Infisical/infisical/latest/docs#service_token-1) (String, Sensitive) (DEPRECATED, Use machine identity auth), Used to fetch/modify secrets for a given project

[](https://registry.terraform.io/providers/Infisical/infisical/latest/docs)

### [Nested Schema for `auth`](https://registry.terraform.io/providers/Infisical/infisical/latest/docs#nested-schema-for-auth)

Optional:

*   [`aws_iam`](https://registry.terraform.io/providers/Infisical/infisical/latest/docs#aws_iam-1) (Attributes) The configuration values for AWS IAM Auth (see [below for nested schema](https://registry.terraform.io/providers/Infisical/infisical/latest/docs#nestedatt--auth--aws_iam))
*   [`kubernetes`](https://registry.terraform.io/providers/Infisical/infisical/latest/docs#kubernetes-1) (Attributes) The configuration values for Kubernetes Auth (see [below for nested schema](https://registry.terraform.io/providers/Infisical/infisical/latest/docs#nestedatt--auth--kubernetes))
*   [`oidc`](https://registry.terraform.io/providers/Infisical/infisical/latest/docs#oidc-1) (Attributes) The configuration values for OIDC Auth (see [below for nested schema](https://registry.terraform.io/providers/Infisical/infisical/latest/docs#nestedatt--auth--oidc))
*   [`organization_slug`](https://registry.terraform.io/providers/Infisical/infisical/latest/docs#organization_slug-1) (String) When set, this will scope the login session to the specified organization the machine identity has access to. If left empty, the session defaults to the organization where the machine identity was created in.
*   [`token`](https://registry.terraform.io/providers/Infisical/infisical/latest/docs#token-1) (String, Sensitive) The authentication token for Machine Identity Token Auth. This attribute can also be set using the `INFISICAL_TOKEN` environment variable
*   [`universal`](https://registry.terraform.io/providers/Infisical/infisical/latest/docs#universal-1) (Attributes) The configuration values for Universal Auth (see [below for nested schema](https://registry.terraform.io/providers/Infisical/infisical/latest/docs#nestedatt--auth--universal))
